# Грин-Стоун — тестовая версия сайта

Полностью переработанный дизайн и вёрстка сайта гранитной мастерской.
Картинки и цены — те же, что на текущем сайте; всё остальное сделано заново.

```
site/
├── index.html              одна страница целиком
├── assets/css/main.css     дизайн-система + все секции + адаптив
├── assets/js/main.js       вся логика, один файл без зависимостей
├── vercel.json             заголовки и кеш для Vercel
└── robots.txt              на время теста индексация закрыта
```

Зависимостей и сборки нет. Открывается двойным кликом по `index.html`;
в VS Code удобно запускать через расширение **Live Server**.

---

## Деплой на Vercel (≈ минута)

**Вариант 1 — из GitHub (рекомендую).**

1. <https://vercel.com/new> → **Import Git Repository** → этот репозиторий.
2. **Root Directory** → `site` (обязательно, иначе Vercel увидит Python-бота).
3. Framework Preset → **Other**. Build Command и Install Command оставить пустыми.
4. **Deploy**.

Дальше каждый `git push` в ветку будет автоматически обновлять сайт.

**Вариант 2 — из терминала.**

```bash
npm i -g vercel
vercel login
vercel --cwd site          # превью-ссылка
vercel --cwd site --prod   # боевой домен
```

## Что поменять перед боевым запуском

| Где | Что |
| --- | --- |
| `assets/js/main.js`, `FORM_ENDPOINT` | Пустая строка = демо-режим: заявка никуда не уходит, показывается экран «принято». Впишите URL обработчика — форма начнёт слать `POST` с JSON `{name, phone, email, message, page, at}`. |
| `assets/js/main.js`, `PRICE` | Цены дополнений: ограда 543, ваза 230, бронзовая буква 14 — взяты с текущего сайта. Гравировка, фундамент и благоустройство идут строкой «по замеру». |
| `index.html`, секция «Журнал» | Тексты материалов в `data-body` — заглушки. Замените на реальные статьи. |
| `index.html`, секция «Контакты» | Указан один адрес. Когда будут все 13 офисов — добавим список с поиском по районам. |
| Картинки | Сейчас грузятся по прямым ссылкам с `green-stone.by`. Для продакшена лучше перенести файлы к себе и раздавать через `/assets/img` — так быстрее и не зависит от чужого хостинга. |
| `robots.txt` | Убрать `Disallow: /`, когда сайт станет боевым. |
